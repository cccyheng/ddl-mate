# 任务批量管理

2026-11-03，本轮执行方 Codex，用户明确授权“你自己做”。

任务列表 → 批量管理：逐条勾选，或全选当前筛选中的未完成任务。每次最多 100 条；已完成、已取消不参与。改变关键词、课程或状态筛选会清空选择；排序不清空。

支持批量完成、统一截止日期、明确清除截止日期。日期和时间沿用浮窗滚轮，允许仅日期；空白日期不隐式清除。确认框列出每条任务标题和操作，取消不写入。保存后显示更新与无需修改的数量。退出批量模式恢复原任务卡片与单条操作。

领域层对完整任务字段做固定顺序指纹，预览固定 ID、指纹和恢复代次。AppStore 共享写队列在执行时再次检查备份写入门禁和恢复代次。数据库在一个事务内核对所有目标再更新，仅修改目标字段；任何写入失败全部回滚。批量完成沿用 completedAt 语义，不调用切换完成状态，重复旧预览会被拒绝。说明、课程、步骤、原文、截图不在更新语句中。

提交后调用现有任务提醒对账：完成取消提醒，截止变化重算提醒。列表刷新或通知同步失败不撤销已保存数据；通知服务的异步失败沿用 ReminderSyncNotice。选择模式登记导航草稿，退出解除，避免通知点击覆盖选择和滚轮。恢复备份清空旧选择与预览。

验证：10 项新增领域、真实 SQLite、AppStore 与实际 TSX 回调测试；56 项现有提醒、通知导航和时间滚轮回归；TypeScript 检查通过。真实 iOS manifest 和 bundle 返回 200，身份、SDK 58、新入口和既有功能标记通过。未进行 iPhone 原生视觉自动化，不把组件回调测试当作真机验收。

手机验收：用两条测试任务进入批量管理，试日期仅到天、取消预览、确认日期、清除截止和批量完成；关闭重开验证持久化。筛选变化应清空选择，原任务截图和说明应仍在。

本轮无依赖、锁文件、数据库结构、数据库路径或 App 身份变更。

# 番茄钟、休息与到时提醒

入口保持不变：今天 → 学习工具 → 专注计时；或任务 → 任务工具 → 学习安排 → 专注计时。无活动时，在「计时方式」选择正计时或番茄钟。正计时原有行为保留。

番茄钟默认专注 25 分钟、休息 5 分钟。点击时长打开浮窗滚轮，专注可选 1–180 分钟，休息可选 1–60 分钟；取消不会提交草稿。已开始的一轮保留开始时的设置，不能中途改模式。

## 一轮的过程

- 开始后倒计时，暂停不扣剩余时间，继续时重新计算到时点。
- 切后台、关闭重开按时间戳恢复。到零后显示「本轮完成 · 等待保存」，不会把晚回到应用的时间算入学习时长。
- 可以提前结束并保存实际时长；也可以「保存并开始休息」，一次写入完成保存与阶段切换。
- 休息可以暂停、提前结束或「开始下一轮专注」。休息不会进入学习记录和周报，下一轮必须由用户明确开始，不在后台自动循环。
- 保存失败可重新读取后重试；重复操作使用修订号拒绝，恢复备份前的旧页面不能写入新数据。

这仍是经过时间的记录，并不检测用户是否真实在学习。正计时保留原有超过 12 小时和时钟倒退的提示；番茄钟有效时长始终不超过设定时长。系统时钟倒退会阻止继续保存，需校准或明确舍弃未确认时段。

## 手机到时提醒

默认关闭，用户明确选择「开启」才可能申请本地通知权限。仅为正在运行的番茄专注或休息安排一次性提醒；正计时、暂停和已过到时点不新增提醒。开启不等于排程成功，页面单独显示系统回读确认的时间或错误，并允许重新同步。

暂停、放弃、提前结束和阶段切换会清理本轮所属提醒，继续时按剩余时间重新安排。所有模块共用最终的系统通知排程队列和 60 条容量保护，不取消其它任务或课前提醒。通知调用失败不回滚已经保存的计时状态。回到前台和重开时重新核对；错过的通知不会补发。

点击通知显示提示条，用户点「查看番茄钟」才导航。先验证当前数据代次、会话编号、阶段及到时点，数据库读取后再次检查；已结束、暂停或重新计时的旧通知只显示说明，不跳到另一轮。编辑页面及未保存的专注设置不会被抢走。恢复备份前的通知失效。

声音和实际送达受 iOS 通知权限、专注模式和 Expo Go 能力影响。电脑测试验证了通知调用和状态处理；真正的后台送达仍需 iPhone 验收。

## 数据与备份

继续使用既有 SQLite 设置键 `focus.sessions.v1`，增加可选的计时模式、专注/休息分钟数与提醒开关；旧记录缺这些字段时按正计时读取，无数据库结构和依赖变更。

备份包含历史、活动阶段及设置。恢复后活动变为暂停，保留已暂停保存的区间，丢弃没有确定结束点的连续时段，并关闭到时提醒；用户重新确认后才能继续和开启。旧备份没有专注数据时仍可正常恢复为空。休息活动不会混入学习历史。

手机建议：设置 1 分钟专注、1 分钟休息，开启提醒；开始后切到桌面，等到时后点击通知，再确认保存并休息。检查提醒、跳转、休息不计时和周报；再暂停一轮，关闭重开验证剩余时间保留。

# 专注计时与学习时长

2026-11-02 更新：已加入番茄倒计时、休息和本地到时提醒，详见 [番茄钟说明](native-pomodoro.md)。以下保留正计时基础行为。

入口：今天 → 学习工具 → 专注计时；任务 → 任务工具 → 学习安排 → 专注计时。

可以选择未完成任务，或填写自由专注名称。开始、暂停、继续会立即写入手机 SQLite；切后台继续计时，结束需确认后保存。计时使用时间戳，不依靠后台每秒运行，也不表示自动检测到了真实学习行为。结束前的时长不加入今日／本周／周报汇总。

保存任务和课程的名称快照，删除原任务不会删除历史记录，也不会把复用的任务编号误关联到新任务。按北京时间区间拆分跨日和跨周记录。页面每秒刷新数字，离开页面停止刷新；后台恢复后根据时间戳计算。

连续计时超过 12 小时或系统时间倒退时停止正常保存，显示校准／舍弃未确认时段的说明。用户可明确舍弃当前连续时段，保留之前暂停时保存的时段，或放弃整次活动。不会静默记入异常的巨量时长。

备份包含专注记录。恢复后保留历史和已暂停保存的区间，活动记录变为暂停，未结束的连续时段不续算。旧备份不含专注记录时恢复为空。专注操作复用应用写队列与恢复代次检查；快速重复操作和旧页面写入被拒绝。单次设置写入原子完成，写入失败可重新读取后重试。

限制：正计时没有预定结束时间，因此没有到时通知。番茄钟需显式开启本地提醒，并由用户开始下一轮；没有后台自动轮次或云同步。历史按名称展示，不跳转可能已经删除的任务。数据容量受备份安全上限保护；未加入历史删除／编辑功能。电脑端仍用于 Expo Go 开发预览。

本机验证：类型检查；时间区间、时钟异常、真实 SQLite 写入失败及重试；实际 AppStore 队列重复操作、恢复代次与闸门；真实文件备份往返、旧备份与损坏记录拒绝；原学习周报回归。日志在 `.supervision/focus-time-*.log`。这些不等于 iPhone 真机验收。

手机待验收：从两个入口打开同一活动，开始→暂停→继续→后台→重开→结束保存，检查总时长、历史与周报；再做完整备份，恢复后确认计时暂停。确认导航和窄屏排版正常。

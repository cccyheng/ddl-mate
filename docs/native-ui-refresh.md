# DDL Mate 原生界面改版

2026-10-31。用户授权 Codex 完成全局 UI 优化。面向 Expo Go 的原生手机界面，不是网页。

## 设计与开源参考

- [React Native Paper / CardExample](https://github.com/callstack/react-native-paper/blob/main/example/src/Examples/CardExample.tsx)：参考卡片的内容与操作分区、主次按钮。已核对 [MIT 许可证](https://github.com/callstack/react-native-paper/blob/main/LICENSE.md)，Callstack。
- [TaskNexus / TaskItem](https://github.com/hoangsonww/Task-Manager-ReactNative/blob/master/components/TaskItem.tsx)：参考任务摘要、选择状态与编辑入口分离。已核对 [MIT 许可证](https://github.com/hoangsonww/Task-Manager-ReactNative/blob/master/LICENSE)，Son Nguyen。
- [Shopify Restyle](https://github.com/Shopify/restyle)：参考集中维护颜色、间距、组件变体的方式。已核对 [MIT 许可证](https://github.com/Shopify/restyle/blob/master/LICENSE.md)，Shopify。

本轮自行编写 React Native 组件，没有复制第三方代码、截图、字体或品牌，没有增加依赖。沿用森林绿与暖白，统一圆角、标题、状态色、空态和输入框聚焦状态。

## 动效与交互

- 全局按钮：按压缩至 97%，松开回弹；缩放使用原生驱动，不触发业务回调。加载或禁用时禁止提交。
- 底部标签：统一线条图形，选中胶囊渐显并舒展。没有图标字体或额外库。
- 原生页面：系统栈滑入过渡，保留导航历史和返回规则。
- 工具展开、筛选、保存提示：一次短淡入和 6pt 位移，不循环播放。
- 全局只订阅一次系统“减弱动态效果”；设置尚未读取或读取失败时先关闭装饰动画，开启后立即停用；动画和监听随组件卸载清理。
- 输入、滚轮、数据库操作不等待动画。不能仅凭自动测试承诺 60fps，实际手感需要手机验证。

## 验证与限制

- 本轮 50 项聚焦测试通过，覆盖实际按钮回调、动画清理、系统设置竞态、工具入口、考试核对、周报窄屏和截图库返回。
- 另 33 项入口检查中 31 项通过，2 项在改版前快照上同样失败：旧跨标签源码表达式和旧依赖版本断言，未为绿灯删除这些检查。
- 类型检查通过。此前全套检查有 10 个经快照复现的旧断言失败，以及 1 个 OCR 集成测试受本机依赖文件读取权限阻碍；不声称全套测试全部通过。
- 实际 iOS 预览包、SDK/账号身份、新全局组件标记和照片识别服务已经核对；不等同于 iPhone 真机视觉验收。
- 手机待确认：四个主标签显示、工具展开后每个入口、按钮回弹、滚轮确认/取消、原图关闭与返回、大字体、系统减弱动态设置。
- 不修改业务数据、数据库结构、应用身份或依赖版本；原始源码副本位于 `.supervision/global-ui-before-20261030/src`。

# 全局搜索

2026-11-03。入口：今天页“搜索任务、课程、考试与笔记”；任务页“全局搜索 · 课程、考试与笔记”。使用现有手机本地数据，不请求外部搜索服务，不保存搜索历史。

支持全部、任务、课程、考试、笔记与原文分类，显示各类真实结果数量。关键词不区分英文大小写，兼容全角输入、组合字符和多余空格；多个词以空格分开，全部匹配才返回。搜索按完整标题、标题开头、标题包含、其它字段匹配的次序排列，同级顺序稳定。输入按字面文字匹配，不执行正则表达式。

- 任务：标题、说明、通知原文、提交要求/方式、所属课程、授课老师、状态和截止日期。已完成/取消任务也可查到，状态在结果中显示。
- 课程：名称、老师、学期和备注。内部课程代码不参与搜索或展示。
- 考试：type=EXAM 的真实任务，独立于任务分类；打开现有任务/考试详情。
- 笔记与原文：已有任务说明、通知原文和课程备注。当前没有独立笔记库，不创建虚构笔记；同一个来源最多一条笔记结果。该结果与任务/课程结果可以分别出现，数量按结果条目计。

结果显示来源、摘要，每页最多30条。翻页回到顶部；点开详情，再返回保留搜索词、分类和页码。返回刷新数据，修改/删除后重新计算结果。新入口在今天/任务原栈内打开详情，课程编辑、课表、截图库等依赖路由也完整注册，保持原有返回按钮。

打开前通过共享读取队列重查内容是否存在，检查备份操作和恢复代次。删除、恢复备份、读取失败、连续点击、输入改变或离开搜索页面时，不使用旧异步结果跳转。空输入、无结果、加载、读取失败分别展示；读取失败不当作“没有内容”。

搜索对象为已保存文字，不对照片重新做 OCR。没有新增数据库结构、依赖、账号配置或 App 标识，也不改变真实任务、课程或截图。

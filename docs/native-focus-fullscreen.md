# 沉浸式全屏专注钟

入口仍在「今天 → 学习工具 → 专注计时」或「任务 → 任务工具 → 学习安排 → 专注计时」。普通页面保留计时方式、时长滚轮、任务、到时提醒、今日/本周时长和专注记录；在专注页点击「全屏准备 / 全屏专注 / 全屏休息」进入沉浸视图。真正开始一段新专注成功后会自动进入全屏，无需再点一次。

## 展示与操作

- 全屏用原生 `Modal` 覆盖导航标题栏和底部标签栏；暖白纸色、深绿主色，休息只加一点暖赭石。时间是大号等宽数字，任务名和当前状态保持小字；有倒计时时显示一条细进度线。
- 进行中只保留两条主操作：暂停/继续，以及结束并保存/结束休息。番茄专注的「保存并开始休息」、休息的「开始下一轮专注」、以及「放弃本次」收在 44pt 的「更多操作」内联展开里；到零后把保存并休息/开始下一轮提升为主操作，结束仍为次操作，放弃仍在「更多操作」里。正计时不显示休息入口。阶段变化（暂停/继续、进行中→到时、休息→专注、结束→准备）会自动收起更多操作。
- 「退出」在安全区内，触控目标至少 44pt。退出只关闭展示，不暂停、不重置、不保存、不放弃计时；设置、提醒、历史记录仍在普通页面。全屏只在活动状态显示一句「退出后计时继续」。
- 写入或确认进行中时，退出/返回/顶部退出都被拦住，顶部显示「保存中…」，不会在全屏 Modal 关闭过程中再挂一个普通确认对话框。正常退出会先清掉确认状态再关闭；内联确认的取消不会写入。完成、放弃、舍弃未确认时段和开始下一轮沿用原确认文案与危险色。全屏内确认卡直接叠在同一层视图里，不再打开第二个原生 Modal；取消保留原状态，确认按钮在写入期间禁用，底层 `act` 还有同步锁，连点只提交一次。失败信息显示在仍可见的全屏表面，并提供重新读取。
- 恢复备份、页面失焦或卸载时收起全屏；计时状态仍由原 `FocusTimeScreen` 的 snapshot、写队列、revision/generation 和草稿保护管理，没有第二套时钟。后台计时、暂停/恢复、到时封顶、休息不计入、手动下一轮、提醒、统计和备份行为均未改动。

## 小屏与辅助功能

全屏内容放在滚动容器里：小屏、横屏或大字号时可以滚动，按钮不会因为固定高度被裁掉；任务名最多两行并尾部省略，按钮和退出入口保持 44pt 以上。时间字号按可用宽高和系统字号计算，再允许系统缩放与自动缩小。全屏只有一次短的 Modal 淡入；系统开启“减少动态效果”时改为无动画。没有持续装饰动画。

## 验证与边界

`mobile/tests/focusFullscreen.test.mjs` 校验原生 Modal 全屏属性、四边安全区、44pt 退出、等宽大时钟、内联确认只有一个 Modal、取消/确认分离、错误和重试、暂停/休息/到时/异常/加载/准备状态、更多操作展开/收起、阶段切换与重新进入复位、写入中禁止退出、小屏/横屏/大字号布局。`mobile/tests/focusTimeScreen.test.mjs` 校验进入/退出不写入、开始自动进入、暂停/继续共用原 act、确认取消/确认/失败、连点一次写入、写入中退出被拦住且不出现第二个 Modal、到时保存并休息、手动下一轮、失焦与恢复代次。2026-11-03 最终聚焦 65 项测试通过，TypeScript `--noEmit` 通过；日志在 `.supervision/focus-fullscreen-*-final*.log`。

电脑测试不等于 iPhone 真机验收。原生 Modal 对导航/标签栏的实际覆盖、刘海与 Home 指示条安全区、状态栏颜色、系统大字号下的视觉比例、横屏滚动、以及从全屏退出后立刻打开滚轮/设置的呈现时序，仍需在 Expo Go / iOS 真机检查。没有新增依赖、数据库结构、备份格式或应用标识。

# 专注记录管理

2026-11-03：本版交付完成。用户确认手机上“补记、修改、重开和删除都正常”。用户明确要求 Codex 直接实施本版。

## 使用入口

进入「专注计时」，向下找到「专注记录」。

- 查看明细：展示每段有效学习时间及总时长；日期、时刻按北京时间显示到秒，暂停间隙不计时。
- 补记学习时段：填写学习内容、可选课程名称，并通过浮窗滚轮选择日期和时间；支持多个学习时段，核对后确认保存。
- 更正这条记录：修改名称或逐段时间。只改名称时原始秒数和暂停间隙完整保留；改动时间后以更正值重新计算。
- 删除这条记录：先显示将减少的时长，明确确认后删除，不能直接撤销。只影响专注记录，不删除任务或课程。

补记标注“手动补记”，再次修改记录标注“已手动更正”。更正时段后不再用原番茄钟计划时长限制新记录；时间完全未改则保留原计时配置。名称是历史快照，不关联可被复用的任务编号。

## 时间与数据规则

每段必须结束晚于开始，不能位于未来、倒序或重叠，单段连续时长最多12小时。整条记录的起止范围不能与另一条记录重叠，原记录的暂停间隙也不能插入另一条记录。每条最多2000个时段、整个存储最多10000条记录，继续沿用现有存储容量限制。错误会在确认前提示，落库时仍再次校验。

正在专注、暂停或休息时，历史记录只读，先结束当前活动再补记／更正。编辑记录期间不能开始新计时；通知跳转沿用现有草稿保护。原始未改动时刻保留毫秒，新选时刻精确到分钟。

沿用 `focus.sessions.v1` 和现有共享读写队列，没有新增表或依赖。补记按时间排序，编号不重复使用；原始编辑版本与恢复代次随草稿捕获，自动刷新不能让旧草稿获得新版本后覆盖记录。保存失败保留草稿，重复点击只提交一次。

周目标、今天统计和周报使用相同的有效时间段汇总。补记、更正和删除后，返回相应页面读取最新结果；跨日、跨周按北京时间边界切分。备份保留手动来源及更新时间，旧备份没有这些字段仍可恢复。
